iPedia | Φυσική Β΄ Γυμνασίου — SEO optimized
=============================================

1. Δημοσιεύστε ΟΛΟ το περιεχόμενο του φακέλου iPedia_Physics_BG_Landing/
   στον φάκελο της ιστοσελίδας https://ipedia.online/physics_BG/
   Μην παραλείψετε τον υποφάκελο assets/ και τα αρχεία του οδηγού.

2. Βεβαιωθείτε ότι η βασική σελίδα ανοίγει στη:
   https://ipedia.online/physics_BG/
   (κανονική διεύθυνση / canonical). Αν το URL διαφέρει, πρέπει
   πρώτα να τροποποιηθούν τα canonical, og:url και τα JSON-LD URLs.

3. Το sitemap βρίσκεται στο:
   https://ipedia.online/physics_BG/sitemap.xml
   Υποβάλετέ το στο Google Search Console.
   Για robots.txt στον ΡΙΖΙΚΟ φάκελο του domain ανατρέξτε στις
   οδηγίες DOMAIN_ROOT_OPTIONAL/. ΜΗΝ αντικαταστήσετε υπάρχον robots.txt.

4. Το Open Graph αρχείο βρίσκεται στο assets/og-physics-bg.jpg
   Για κοινή χρήση σε Facebook/X χρησιμοποιούνται απόλυτα URL και HTTPS.

5. Οι εικόνες της ιστοσελίδας δεν ενσωματώνονται πια ως Base64.
   Το κάλυμμα βιβλίου έχει προτεραιότητα φόρτωσης· οι 11 σελίδες
   έχουν ελαφριές μικρογραφίες και χωριστές εικόνες υψηλής ανάλυσης
   που φορτώνονται όταν ανοιχθεί η μεγέθυνση.

6. Οι σύνδεσμοι Apple Books διατηρήθηκαν όπως στο τελευταίο ZIP:
   Πάνω μενού / κεντρικό κουμπί / τελικό CTA: https://apple.co/3vccl7h
   Μόνο σύνδεσμος στο footer: https://apple.co/2Q7Blxq

7. Δοκιμές μετά τη δημοσίευση:
   - ανοιχτό PDF και HTML Οδηγού Εκπαιδευτικού,
   - 11 προεπισκοπήσεις/μεγέθυνση, προσομοίωση και μενού κινητού,
   - έλεγχος Google Search Console, PageSpeed Insights / Core Web Vitals.

8. Για βέλτιστη ταχύτητα, αν το επιτρέπει η φιλοξενία, ενεργοποιήστε
   Brotli ή gzip για HTML και caching για τα αρχεία assets.

Η βελτιστοποίηση αφορά τον κώδικα και τα assets. Δε συνιστά βεβαίωση
ότι η δημοσιευμένη σελίδα έχει περάσει Core Web Vitals, ότι είναι
ήδη indexed από την Google ή ότι υπάρχουν εγγυημένες SEO κατατάξεις.
